# Social-card font

`AtkinsonHyperlegible-Bold.bin` contains the unmodified Atkinson Hyperlegible Bold
TrueType font, bundled as a Worker binary module. Source:
https://github.com/google/fonts/tree/main/ofl/atkinsonhyperlegible
